# Muse World Waitlist

Premium waitlist landing page for Muse World (3,333 soft fluffy creatures, free mint on Robinhood Chain).

- Static site: `index.html` + `assets/`
- Form posts to a Google Form response endpoint (see `FORM_CONFIG` in `index.html`); a sync job copies new responses into the "Muse World Waitlist" Google Sheet.
- Foxora holder check runs live on-chain against Robinhood Chain (4663) via public RPCs.
- No wallet connect, no signatures, no transactions anywhere on the page.

Draft preview only. Do not announce publicly.
